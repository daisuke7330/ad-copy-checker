# 広告原稿 表記チェッカー

広告・LP・チラシの原稿を貼るだけで、入稿前に直したい表記をまとめて見つけるWebツールです。
文章はブラウザの中だけで調べ、サーバーには送信しません（公開前の原稿でも安心して使えます）。

## できること

| チェック | 例 | 自動修正 |
|---|---|---|
| 機種依存文字 | ① ㈱ ㎏ Ⅱ | (1) (株) kg II |
| 半角カナ | ｸﾞﾙｺｻﾐﾝ | グルコサミン |
| 全角英数字（半角と混在している時） | １日2粒 | 1日2粒 |
| 余分な空白 | 連続した空白・行末の空白 | 1つに／削除 |
| 税込・税抜の表記なし | 送料 550円 | ― （内容を見て人が直す） |
| 注意が要る表現 | No.1・最高・治る・今だけ・通常価格 など | ― （言い換えを検討） |

- 入力するとすぐにチェック（ボタン不要）、原稿に色を付けて表示
- 指摘をクリックすると原稿のその場所を選択
- 種類ごとに表示・非表示を切り替え
- 「自動で直せるものを直した原稿をコピー」で、表記だけ直した原稿をクリップボードへ
- 文字数（空白・改行を除いた数も）を表示

※「注意が要る表現」は言い換えを検討するきっかけで、使ってよいかの最終判断は媒体の考査・社内ルールに従ってください。

## 使い方

公開URLを開いて原稿を貼るだけです。インストールや登録は不要です。

## 技術

- HTML / CSS / JavaScript（ES Modules）だけで動く静的サイト
- チェックのルールは `rules.js` にまとめ、画面（`app.js`）と分離
- テスト：`npm test`（Node.js の標準テストランナー）
- 公開：Vercel（GitHub の main に push すると自動で反映）
