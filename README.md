# 広告原稿 表記チェッカー

広告・LP・チラシの原稿を貼るだけで、入稿前に直したい表記をまとめて見つけるWebツールです。
文章はブラウザの中だけで調べ、サーバーには送信しません（公開前の原稿でも安心して使えます）。

## できること

チェック結果は「人が見る所」と「自動で直る表記」に分けて、人が見る所を先に出します。

| 分類 | チェック | 例 | 自動修正 |
|---|---|---|---|
| 人が見る所 | 注意が要る表現 | No.1・第1位・最高・治る・血圧が下がる・今なら・先着・50%OFF・通常価格 など | ― |
| 人が見る所 | 条件の確認 | 定期・初回・2回目以降・〇回以上・送料無料・返品・解約・全額返金保証 | ― |
| 人が見る所 | 税込・税抜の表記なし | 送料 550円・￥2,980（価格ごとに近くの「税込」「＋税」を確認。原稿全体の「表示価格はすべて税込」も可） | ― |
| 自動で直る表記 | 機種依存文字 | ① ㈱ ㎏ Ⅱ（髙・﨑など人名に使う字は指摘のみ） | (1) (株) kg II |
| 自動で直る表記 | 半角カナ | ｸﾞﾙｺｻﾐﾝ | グルコサミン |
| 自動で直る表記 | 英数字の全角・半角の混在 | １日2粒・０１２０－… | 横書きは半角、縦書きは全角にそろえる |
| 自動で直る表記 | 余分な空白 | 文中で続く空白・行末の空白（行頭の字下げは対象外） | 1つに／削除 |

- 入力するとすぐにチェック（ボタン不要）、原稿に色を付けて表示
- 「人が見る所」には「回覧でのひと言」（担当者に何を聞けばよいか）を添える
- 指摘をクリックすると原稿のその場所を選択、「無視」で個別に消せる
- 種類ごとに表示・非表示を切り替え（非表示の種類・無視した指摘は自動修正もしない）
- 「自動で直る表記を直した原稿をコピー」で、表記だけ直した原稿をクリップボードへ
- 英数字のそろえ方を「半角（横書き・LP）」「全角（縦書き・新聞）」から選べる
- PDFや紙から写して「5,000（改行）円」のように崩れた価格も拾う
- 文字数（空白・改行を除いた数も）を表示

※「人が見る所」は確認や言い換えを検討するきっかけで、使ってよいかの最終判断は媒体の考査・社内ルールに従ってください。

## 使い方

公開URL：https://ad-copy-checker.vercel.app

URLを開いて原稿を貼るだけです。インストールや登録は不要です。

## 技術

- HTML / CSS / JavaScript（ES Modules）だけで動く静的サイト
- チェックのルールは `rules.js` にまとめ、画面（`app.js`）と分離
- テスト：`npm test`（Node.js の標準テストランナー）
- 公開：Vercel（GitHub の main に push すると自動で反映）
